
# Linux Security Audit Toolkit

## Project Overview

Linux Security Audit Toolkit is a Python-based security assessment tool designed to automate common Linux security checks and provide a structured overview of system security posture.

The toolkit collects information about the operating system, local users and privileged accounts, SSH configuration, network connections, running services, firewall configuration, sensitive file permissions, and authentication-related logs.

The collected information is analyzed to identify potentially risky configurations and security findings. A project-defined risk scoring system is then used to calculate an overall security score and risk level.

The toolkit also generates an HTML security report containing the assessment results, findings, severity levels, and security recommendations.

## Project Objective

The objective of this project is to demonstrate practical cybersecurity skills by combining Linux system administration, Python automation, security assessment techniques, risk analysis, testing, and technical reporting into a single reproducible security tool.

## Security Scope

The toolkit is intended for authorized security assessments of Linux systems. Its findings are designed to support security review and prioritization rather than replace a complete penetration test, vulnerability assessment, or professional security audit.
