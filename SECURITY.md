# Security Policy

## Purpose

The Linux Security Audit Toolkit is a cybersecurity project designed for authorized Linux security assessments and educational use.

If you discover a security vulnerability in the project itself, please report it responsibly rather than publicly disclosing details before a fix or mitigation can be considered.

## Reporting a Vulnerability

Please report potential vulnerabilities through GitHub's private vulnerability reporting feature when it is available for this repository.

If private vulnerability reporting is not available, open a GitHub issue without including sensitive exploit details, credentials, private information, or a complete proof-of-concept that could unnecessarily increase risk.

When reporting a vulnerability, please provide:

* A clear description of the issue.
* The affected component or file.
* Steps required to reproduce the issue, when safe to provide.
* The potential security impact.
* Any suggested mitigation, if known.

## Responsible Disclosure

Please allow reasonable time for the issue to be investigated and addressed before publicly disclosing detailed vulnerability information.

Do not include:

* Passwords or credentials.
* Private keys or tokens.
* Personal or sensitive information.
* Information obtained from systems without authorization.
* Exploit instructions that could unnecessarily facilitate abuse.

## Supported Versions

The latest version of the project is the primary version supported for security fixes.

Older versions may not receive security updates.

## Scope

Security reports may concern issues such as:

* Vulnerabilities in the Python code.
* Unsafe command execution.
* Improper handling of system information.
* Insecure file operations.
* Sensitive information exposure.
* Security issues in report generation.
* Dependencies with relevant security vulnerabilities.

The toolkit's security findings about a scanned Linux system are not themselves vulnerabilities in the toolkit. They are assessment results produced by the project.

## Authorized Use

This project is intended for systems that you own or have explicit authorization to assess.

The project should not be used to access, modify, or interfere with systems without permission.
